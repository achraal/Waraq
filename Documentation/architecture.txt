La Logique de Découpage et d'Analyse
               ┌──────────────────────────────┐
               │  Document (PDF / Word conv)  │
               └──────────────┬───────────────┘
                              │
                    Nombre de pages ?
                              │
         ┌────────────────────┴────────────────────┐
         ▼                                         ▼
   [ < 20 Pages ]                            [ >= 20 Pages ]
         │                                         │
 ┌───────┴────────────────────────┐       ┌────────┴────────────────────────┐
 │ 1. PAS de découpage physique. │       │ 1. Scan des en-têtes/titres     │
 │ 2. Classifier le doc global.  │       │    en haut de chaque page.      │
 │ 3. Inspecter le contenu pour  │       │ 2. Si rupture Majeure (RC/CPS): │
 │    détecter et Lister les     │       │    -> Découpage Physique.       │
 │    modèles / annexes inclus.  │       │ 3. Lister aussi les annexes/    │
 └────────────────────────────────┘       │    modèles détectés dedans.    │
                                          └─────────────────────────────────┘
